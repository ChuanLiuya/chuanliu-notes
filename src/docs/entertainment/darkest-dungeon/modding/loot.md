# 战利品表（Loot）

> 译自 Steam 官方指南《Darkest Dungeon - Modding Guide [Official]》中的战利品（Loot）相关章节，内容保持原文结构与表述。

战利品表都集中在单个文件中。扫描这个文件通常就能看到足够多的示例，帮助你完成大多数想做的改动。下面提供几个示例，并说明如何操作、理解其中的一些变量。

## 变量

| 变量 | 说明 |
| --- | --- |
| `id` | 绑定到该战利品表的 id。 |
| `difficulty` | 该表适用的难度。如果设为 `0`，则所有难度都可以调用该表。 |
| `dungeon` | 该表适用的地牢。如果留空，则该表为通用表。 |
| `entries` | 与该表关联的条目列表。 |

## 可引用的物品列表

- 补给品（Provisions）
- 金币（Gold）
- 传家宝（Heirlooms）
- 宝石（Gems）
- 物资（Supplies）
- 日志页（Journal Pages）
- 饰品（Trinkets）
- 其他战利品表（Other loot tables）

::: tip 日志页
日志页可以引用页码范围，也可以引用某一页。
:::
