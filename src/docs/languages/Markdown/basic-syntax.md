# 基本语法

## 一、标题语法

使用 `#` 号标记，一个 `#` 是一级标题，最多六级：

| 样式     | 语法              | 效果              |
| -------- | ----------------- | ----------------- |
| 一级标题 | `# 一级标题`      | <h1>一级标题</h1> |
| 二级标题 | `## 二级标题`     | <h2>二级标题</h2> |
| 三级标题 | `### 三级标题`    | <h3>三级标题</h3> |
| 四级标题 | `#### 四级标题`   | <h4>四级标题</h4> |
| 五级标题 | `##### 五级标题`  | <h5>五级标题</h5> |
| 六级标题 | `###### 六级标题` | <h6>六级标题</h6> |

::: tip

重要的是语义，而不是效果。通常这个效果是可更改的，在不同网站上显示不同。例如我可以设置二级标题的大小比一级还大，或者设置三级标题的颜色为红色等等。重要的是“一级标题”“二级标题”的含义，其他同理。

:::

## 二、段落与换行

**语法：**

直接书写即为段落。段落之间用空行分隔。  
行末加两个空格再回车可实现段内换行。

```

这是第一段，和下面那段之间有一个空行。

这是第二段，与第一段分开显示。

这是同一段，
但这里换行了（行末有两个空格）。
```

**效果：**

这是第一段，和下面那段之间有一个空行。

这是第二段，与第一段分开显示。

这是同一段，  
但这里换行了（行末有两个空格）。

## 三、文字样式

| 样式     | 语法                     | 效果         |
| -------- | ------------------------ | ------------ |
| 粗体     | `**粗体**` 或 `__粗体__` | **粗体**     |
| 斜体     | `*斜体*` 或 `_斜体_`     | _斜体_       |
| 粗斜体   | `***粗斜体***`           | **_粗斜体_** |
| 删除线   | `~~删除线~~`             | ~~删除线~~   |
| 行内代码 | `` `code` ``             | `code`       |

## 四、列表

### 无序列表

使用 `-`、`*` 或 `+`：

**语法：**

```markdown
- 项目一
- 项目二
  - 子项目
  - 子项目
```

**效果：**

- 项目一
- 项目二
  - 子项目
  - 子项目

### 有序列表

使用数字 + 点号：

**语法：**

```markdown
1. 第一步
2. 第二步
   1. 子步骤
   2. 子步骤
3. 第三步
```

**效果：**

1. 第一步
2. 第二步
   1. 子步骤
   2. 子步骤
3. 第三步

### 任务列表

**语法：**

```markdown
- [x] 已完成
- [ ] 待完成
- [ ] 待完成
```

**效果：**

- [x] 已完成
- [ ] 待完成
- [ ] 待完成

## 五、链接与图片

### 链接

**语法：**

```markdown
[链接文字](https://example.com)
[带标题的链接](https://example.com "鼠标悬停显示")
<https://example.com>
```

**效果：**

[链接文字](https://example.com)

[带标题的链接](https://example.com "鼠标悬停显示")

<https://example.com>

### 图片

**语法：**

```markdown
![VitePress](https://vitepress.dev/vitepress-logo-mini.svg)
![替代文字](https://there.is.not.a.real.url.com)
```

**效果：**
![VitePress](https://vitepress.dev/vitepress-logo-mini.svg)
![替代文字](https://there.is.not.a.real.url.com)

## 八、表格

**语法：**

```markdown

| 内容 | 内容 | 内容 |

**效果：**

| 列1  | 列2  | 列3  |
| ---- | ---- | ---- |
| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |

| :----- | :--: | -----: |
| 左     |  中  |     右 |
```

**效果：**

| :----- | :--: | -----: |
| 左     |  中  |     右 |

## 九、分隔线

**语法：**

要创建分隔线，请在单独一行上使用三个或多个星号 (\*\*\*)、破折号 (---) 或下划线 (\_\_\_) ，并且不能包含其他内容

```markdown
***

---

_________________________________
```

**效果：**

***

---

_________________________________

::: tip 提示
官方文档说，请在分割线上下各空一行来为了兼容性。
:::
