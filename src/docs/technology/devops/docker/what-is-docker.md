# 什么是Docker？

简单来说，docker就是用容器化技术，给应用程序封装独立的运行环境。每个运行环境都是一个容器。

运行容器的计算机被称为宿主机。

docker容器与虚拟机的区别是：docker容器之间共用一个系统内核，而每个虚拟机都包含一个操作系统的完整内核，所以docker比虚拟机更轻，更小。
